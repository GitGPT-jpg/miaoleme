🍎 macOS

本次临时页只托管 Windows 包（macOS 安装包超过本页 100MB 限制）。 Mac 版请向作者索取 .dmg，或从项目仓库构建：npm ci && npm run dist。

使用说明

首次使用：打开控制台 → 设置 → 图像生成服务 → 填写并保存（未配置时上传照片只会显示原图）。

内测说明：Windows 包基于 Electron 33（受本页 100MB 托管上限约束）；macOS 版为 Electron 45。

  1. 解压后双击 喵了么.exe，桌宠会出现在屏幕角落，控制台随启动打开
  2. 关闭控制台不会退出，程序常驻在系统托盘（小猫头图标）
  3. 上传自己的照片可生成 3D 形象（需配置生成服务；未配置时使用原图）
  4. 数据保存在本机 %APPDATA%\miaoleme，不联网上传（除你主动启用的形象生成）
