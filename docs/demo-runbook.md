# 路演演示 Runbook（明天）

> 目标：本机 5 分钟内跑通全部核心功能，不依赖现场网络。
> 应用：`/Applications/喵了么.app`（或 `npm start`）

## 0. 上台前 5 分钟（必做）
1. `node tools/demo-seed.js` —— 写入演示数据（会议 +6 分钟、DDL +2 小时、菜单/战绩/统计）
2. 启动应用，把桌宠拖到屏幕右下角（避开 Dock）
3. 控制台 → 设置：确认「图像生成服务」显示已配置（若未配置，现场只演示原图+骨骼，不现场生成）
4. 系统设置 → 通知：确认允许「喵了么」通知（否则会议/DDL 不弹）
5. 关闭免打扰；关闭安静模式
6. 提前跑一遍「一键演示」确认顺序正常（约 30 秒）

## 1. 演示动线（约 4 分钟）
| 时间 | 操作 | 讲解点 |
|---|---|---|
| 0:00 | 桌面展示桌宠（呼吸/眨眼/摆尾/跟随鼠标） | “它一直在动，不是静态贴图；视线会跟着你” |
| 0:30 | 悬停桌宠 → 底部四个按钮 | “喂水/喂粮/游戏/控制台都在手边” |
| 0:50 | 托盘 → 切换形态（喵喵/小铁/咕叽） | “三种形态，随时换” |
| 1:10 | 控制台 → 桌宠 → 上传我的图片 | “任何照片都能变成它的样子”（已在演示前生成好则直接展示结果） |
| 1:40 | 说到喝水提醒 → 点“喂水” | “它先讨水，你喂了才算完成——提醒变成互动” |
| 2:10 | 控制台 → 吃饭 → 转盘 → 转！ | “指针指哪就是哪，落点高亮” |
| 2:40 | 控制台 → 专注 → 开始番茄钟 | “专注/休息自动循环，完成计入成就” |
| 3:10 | 控制台 → 游戏 → 石头剪刀布/猜数字 | “陪你摸鱼 30 秒” |
| 3:30 | 托盘 → 一键演示 | 自动串场收尾 |
| 4:00 | 打开会议提醒（+6 分钟到点） | “它会在开会前提醒你，也会催 DDL” |

## 2. 一键演示（兜底）
- 托盘 →「🎬 一键演示（路演）」或 设置 →「开始一键演示」
- 顺序：打招呼 → 伸懒腰 → 打滚 → 吃饭转盘 → 喂水/喂粮 → 番茄钟 → 游戏
- 全程 30 秒，无需点击

## 3. 故障兜底
| 故障 | 处理 |
|---|---|
| 生成服务不可用 | 只演示“原图 + 骨骼动画”，说明“现场网络受限，形象已提前生成” |
| 系统通知不弹 | 检查系统通知权限；改用桌宠气泡讲解提醒逻辑 |
| 桌宠找不到 | 点菜单栏小猫头，或 ⌘+⇧+P |
| 双开导致异常 | 只保留一个实例（第二次启动会自动退出） |
| 演示数据混乱 | `node tools/demo-seed.js --restore` 恢复 |

## 4. 演示后
- 关闭应用或保留；如需恢复个人数据：`node tools/demo-seed.js --restore`
