# Windows 真机验收清单（v0.5.x 内测包）

> 包：`miaoleme-win-x64-*.tar.xz`（Electron 33，受托管 100MB 上限）
> 解压：`tar -xf miaoleme-win-x64-*.tar.xz` → 双击 `喵了么.exe`

## 一、启动与常驻
- [ ] 首次启动出现桌宠 + 控制台；关闭控制台程序不退出
- [ ] 系统托盘出现小猫头图标，右键菜单可用（打开控制台/切换形态/喂水/喂粮/番茄钟/稍后提醒/免打扰/退出）
- [ ] 再次双击 exe 不会出现第二只桌宠（单实例，控制台被唤起）

## 二、桌宠交互
- [ ] 桌宠透明、置顶、可拖动，位置重启后保留
- [ ] 悬停出现底部 4 个按钮（💧 🍽 🎮 ⚙️），不被猫身遮挡、可点击
- [ ] 点击空白处可穿透到下方窗口
- [ ] 空闲时有呼吸/眨眼/尾巴/耳朵动作（骨骼模式）；头部随鼠标微动
- [ ] 切换形态（自定义/喵喵/小铁/咕叽）正常；emoji 形态不显示骨骼

## 三、提醒与喂养
- [ ] 喝水：到点讨水 → 点喂水 → 播放喝水 → 徽标消失
- [ ] 饭点（11:30–13:00 / 17:30–19:00）：猫咪讨粮；喂饭后当天该餐次不再讨
- [ ] 托盘「稍后提醒」只影响当前待处理请求
- [ ] 会议/DDL：提前提醒 + 到点提醒；删除后不再提醒
- [ ] 免打扰时段内不弹系统通知
- [ ] 番茄钟：开始/停止/到点计数一次；退出重开可续跑未到期番茄

## 四、图片与生成
- [ ] 控制台 → 设置 → 图像生成服务：填写地址/身份 → 保存 → 测试连接
- [ ] 上传照片：先显示原图，进度条推进，站立优先出现
- [ ] 生成完成后：6 个姿势 + 5 个骨骼部件；桌宠变为 3D 形象并可眨眼/压耳
- [ ] 快速连续上传两张：最终显示第二张，旧任务不覆盖（无串图）
- [ ] 生成部分失败：显示“x/y + 可重试失败项”，重试只补失败项
- [ ] 未配置服务：上传只显示原图，提示“去配置生成服务”（不假装生成）

## 五、数据与退出
- [ ] 重启后形态、位置、提醒、菜单、战绩、亲密度保留
- [ ] 数据目录：`%APPDATA%\miaoleme`（含 `zerobreak-store.json`、`pet-rig-*.png`）
- [ ] 退出后无残留进程（任务管理器确认）

## 六、已知限制（Windows 内测）
- Electron 33（受 100MB 托管上限），正式分发需升级到 45 并在真机复验
- 未签名：SmartScreen 提示「更多信息 → 仍要运行」
- 生成服务需自行配置（凭据不随包分发）
